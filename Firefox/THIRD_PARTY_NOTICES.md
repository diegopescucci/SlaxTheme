# Musixmatch fallback reference

## AMLL TTML parser

Slax bundles `@applemusic-like-lyrics/ttml` 1.0.1 from
[amll-dev/applemusic-like-lyrics](https://github.com/amll-dev/applemusic-like-lyrics/tree/main/packages/ttml).
This dependency is licensed under AGPL-3.0-only. The full license is included at
`public/licenses/amll-ttml-AGPL-3.0.txt` and shipped as `licenses/amll-ttml-AGPL-3.0.txt`.
The project's ISC package metadata does not override this dependency's license.

## Musixmatch reference

The fallback request signing and endpoint flow in `src/main.js` is adapted from
[Strvm/musicxmatch-api](https://github.com/Strvm/musicxmatch-api).
